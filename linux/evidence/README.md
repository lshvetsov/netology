Опыт занял около 13 минут. Процесс дошёл до 1256 МиБ выделенных блоков, после чего
ядро завершило его. Проверка через cron продолжилась и после OOM.

В первом отчёте ещё есть запись об OOM от предыдущего запуска: скрипт смотрит журнал
за последние 10 минут. Файл `05-kernel.log` содержит только журнал текущего опыта.
Скриншоты сделаны при просмотре сохранённого вывода. В выдержках длинные строки
перенесены; полные журналы оставлены без изменений.
